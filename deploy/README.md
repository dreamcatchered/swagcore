# deploy — конфигурация развёртывания

Эти файлы — **часть репозитория**, а не локальная приватная папка. Раньше
они лежали в `deploy/`, который был добавлен в `.gitignore` при очистке
истории. Из-за этого все правки установщика и nginx жили только на сервере
и были потеряны бы при переезде.

Именно здесь находятся исправления, найденные на живых нодах:

## install.ps1 / install.sh

Установщик ноды. Ключевые места, где легко ошибиться:

- **ExecutionPolicy.** Скрипт исполняется В ПАМЯТИ через
  `[scriptblock]::Create((irm ...).TrimStart([char]0xFEFF))`. Запись в файл
  и запуск `& file.ps1` ломаются на Restricted/RemoteSigned.
- **Кодировка.** Nginx обязан отдавать `.ps1` как
  `text/plain; charset=utf-8`. Без charset PowerShell 5.1 на русской
  Windows (ACP=1251) декодирует UTF-8 как CP1251, в скрипт попадают
  «кавычки» из старших байтов, и парсер падает с `ParseException` **до
  выполнения**. Скрипт дополнительно тянется через `WebClient` с явным
  `Encoding = UTF8`, так что от заголовков сервера он не зависит.
- **`[string]$resp.Content` для `byte[]` даёт `"System.Byte[]"`.** Тип надо
  проверять ДО приведения, иначе сверка sha256 молча пропускается. Именно
  эту ошибку выдавал пользователю предупреждение «манифест sha256 нечитаем».
- **Нативные команды и `$ErrorActionPreference = "Stop"`.** Любая запись
  нативной команды в stderr превращается в `NativeCommandError` и становится
  терминирующей ошибкой. Вызов `agent.exe version` обёрнут в `cmd /c` с
  перенаправлением stderr в файл.
- **Проверка установки.** Установщик ждёт 35 секунд — ровно за ту секунду,
  на которой SCM убивал агента, — и убеждается, что агент подключился по
  своему `agent.log`, а не что сервер платформы отвечает на `/api/health`.
  Раньше проверялось второе, и установка рапортовала успех при мёртвой
  службе.
- **SCM-восстановление.** `sc failure reset= 600 actions=restart/5000/
  restart/10000/restart/30000/restart/60000/restart/120000/restart/600000`.
  Три попытки на сутки (как было) исчерпывались, и после трёх сбоев служба
  больше не поднималась до перезагрузки ПК.
- **Безопасный перенос строк.** Файл отдаётся с CRLF.

## nginx/core.swag.best.conf

Только конфигурация виртуального хоста без сертификатов, IP и путей,
специфичных для машины. Вложенный `location` с `alias` внутри `location` с
`alias` не работает (отдаёт 404 с `text/html`) — типы задаются через блок
`types` внутри `/download/`.

## Что сюда НЕ относится

Отчёты, исследования, инвентарь серверов и любые файлы с реальными адресами
или токенами. Публичный репозиторий не должен содержать ни того, ни другого:
перед коммитом проверяйте, что в новых файлах нет адресов нод и секретов.
